# 📊 Expense Tracker Pro

A modern, interactive web application to track personal expenses, categorize spending, and visualize financial data in real-time. 

## ✨ Features
* **Interactive UI:** Clean, responsive design that works beautifully on both desktop and mobile.
* **Data Visualization:** Real-time dynamic doughnut chart generation using Chart.js.
* **Local Storage:** Your financial data is securely saved directly in your browser—no database required, and no data is lost on refresh.
* **Instant Updates:** Adding or deleting transactions instantly recalculates the total balance and re-renders the charts.

## 🛠️ Built With
* HTML5
* CSS3 (Modern Flexbox & CSS Grid)
* Vanilla JavaScript (ES6+)
* [Chart.js](https://www.chartjs.org/) (Data Visualization)
